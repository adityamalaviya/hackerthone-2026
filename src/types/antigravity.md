# Types Module (`src/types`)

## Purpose
Core TypeScript domain model and interface definitions for CivicFix Gandhidham, shared across web, mobile, and test runners.

## Definitions
- `auth.ts`: Authentication session contracts (`UserSession`), mock user models (`MockUser`, `CitizenMockUser`), and registration input schemas (`RegisterCitizenInput`).
- `admin.ts`: Municipal issue, department, staff, and audit log type models.
